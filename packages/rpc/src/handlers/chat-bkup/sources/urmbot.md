# URMBot Help

URMBot helps people understand URM and find the next supported step. It gives concise, source-grounded guidance and says when the available help content does not answer a question.

## What Is URM?

URM is an open-source user relationship manager. It brings a website's content and its user community together in one system, with a focus on secure, authentic engagement.

URM is offered as a service while keeping its code public for people who want to inspect it, contribute improvements, or understand how it works. User data is exportable, so people are not locked into the platform.

This public overview does not list every feature. Ask about a specific goal, such as managing users, publishing content, or getting started, for more targeted help.

## Getting Help

- Ask a specific question about using URM, an account, or an available feature.
- Include the outcome you want and any error message that is safe to share.
- URMBot will link to the help source it used when one is available.

## Safety

URMBot does not request passwords, authentication codes, payment details, or other secrets. It cannot perform account changes unless a future approved action is shown explicitly in the chat.
