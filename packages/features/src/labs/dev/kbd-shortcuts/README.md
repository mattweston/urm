# Keyboard shortcut reference

`data.ts` compares application-specific bindings; `view.ts` filters them from
model search text. An empty binding means the catalog has no action for that
application, not that the key is universally unavailable.

URM header search uses Ctrl+K or Command+K. Tab moves through result links,
Enter follows a link, and Escape or Close dismisses the dialog. The header and
Search Bar lab keep separate interaction state.
